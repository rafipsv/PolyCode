# Upstream Runtime Licenses

PolyCode incorporates or interfaces with open-source runtimes and toolchains. The licensing terms of candidate runtimes are tracked below:

| Component | Upstream Project | License | Notes |
|---|---|---|---|
| **QuickJS** | QuickJS Javascript Engine | MIT | Permissive, embeddable. |
| **MicroPython** | MicroPython Project | MIT | Permissive, minimal footprint. |
| **Pyodide** | Pyodide / CPython | PSF / Mozilla Public License | Python ecosystem compatibility. |
| **LLVM / Clang** | LLVM Project | Apache 2.0 with LLVM Exception | Toolchain for C/C++ compilation. |
| **Rust Toolchain** | Rust Project | MIT / Apache 2.0 Dual License | Official Rust compiler libraries. |
| **Go Toolchain** | The Go Authors | BSD-3-Clause | Standard Go runtime. |
